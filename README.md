# Radiografía de un género digital

Sitio para estudiantes de Lengua y Literatura (3° medio, Unidad 3): guía paso a paso, ficha de investigación y rúbrica para la exposición oral grupal sobre un género digital. Pensado para revisarse en el celular.

Sitio: https://cifuac.github.io/radiografia-genero-digital/

- La ficha de investigación y el avance se guardan en el celular de cada grupo (no se envían a ningún servidor).
- Las ilustraciones fueron generadas con inteligencia artificial (Gemini).
